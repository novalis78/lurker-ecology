# Lurker Ecology: Rival Embedded Probes and a Falsifiable Resolution of the Fermi Paradox

Lennart Lopin, Euler's Identity LLC. Preprint, October 2026. Prepared for submission to *Acta Astronautica*.

**Claim in one paragraph.** If technological civilizations are common, every explanation of the Great
Silence either lacks enforcement and fails when a few civilizations deviate, or adds local automated
enforcement and becomes a hypothesis about resident self-replicating probes ("lurkers"); zoo, aestivation
and dark forest then differ only in trigger settings. Because the window in which a civilization can be
suppressed is short compared with light-lag, and fast strikes are visible, the enforcer must already be
in the system. Rival lurker lineages face a volunteer's dilemma whose equilibrium is restraint, so
crowding protects a nascent civilization; survivors seed lineages of their own, so late civilizations are
better protected. Earth's survival admits four branches, each with observational consequences: a census
of oxygen worlds and an excess of impact scars among technosignature planets.
